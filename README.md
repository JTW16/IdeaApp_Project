- **팀원 안내** (시연 가이드 · 남은 일 · 기획서 대비 검토 · 제안을 한 파일에): [`idea-helper/팀원_안내.md`](idea-helper/팀원_안내.md)
- 작업 인수인계(Claude Code용): [`CLAUDE.md`](CLAUDE.md)
