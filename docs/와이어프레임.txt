# 1. 카테고리 선택
- 사람들이 많이 쓰는 카테고리는 기본 제공. 단, 사용자가 직접 원하는 카테고리 입력 가능.
- 기본 제공 카테고리는 데이터베이스에 저장된 단어와 사전에 매칭.
- 직접 입력한 카테고리는 데이터베이스에 있는 단어 중 연관이 있는 것들을 매칭

## 1-1. 나만의 카테고리 추가
- 목적: 수백 수천의 카테고리를 개발자가 미리 준비할 수는 없음. 따라서 사용자가 원하는 카테고리를 직접 입력 후 이와 연관 된 단어를 데이터베이스에서 뽑아다가 매칭 시켜주기. 이후 다른 사용자들도 해당 카테고리를 쓸 수 있게 재활용.

# 2. 랜덤 단어
- 선택한 카테고리와 연관된 단어 세 개를 랜덤으로 보여줌.
- 픽스 기  능: 마음에 드는 단어 하나 고정해두고 나머지만 돌릴 수 있는 기능
- 사전 방향성 세팅 기능: 텍스트 입력. 원하는 방향성(예: 매콤한 요리, 튀김 요리 등)을 미리 정해두고 이와 연관된 단어들을 뽑는 기능.
